# 인계 노트 (앱 세션 ↔ Discord 세션)

- 위치: 프로젝트의 `.planning/handoff/YYYY-MM-DD-HHMM-<세션명>.md`. 넘길 때마다 새 파일을 만들고, 이미 있는 노트는 고치지 않는다.
  세션마다 따로 쓰는 이유: 한 프로젝트에 세션이 여럿이라 `HANDOFF.md` 한 파일을 함께 쓰면 서로 덮어쓴다.
  그래서 루트 `HANDOFF.md` 에 쓰는 `/handoff` 스킬은 쓰지 않는다.
- 형식: 목표 / 한 것 / 남은 것 / 막힌 것·결정 필요 / 주의 / 검증 방법, 그리고 아래 셋.
  - **돌고 있는 작업**: 작업마다 명령, 호스트, PID 또는 tmux 세션 이름, 로그 경로, 시작 시각과 예상 종료, 상태 확인 명령, 끝나면 할 일. 없으면 "없음".
  - **판정 대기**: 사용자 판정을 기다리는 것과, 어디에 물어 뒀는지(파일·이슈·채널).
  - **받는 쪽이 먼저 읽을 것**: 인박스, 아침 할 일, 작업로그 경로.
- 한 레인은 한 세션만 맡는다. 노트를 쓴 세션은 그 뒤로 그 레인 일을 하지 않는다(같은 파일 덮어쓰기와 중복 응답을 막는다).
  받는 세션은 이어받았다는 것을 작업로그에 `## HH:MM 이어받음 (<노트 경로>)` 으로 남긴다.
- 돌고 있는 작업은 받는 쪽이 상태 확인 명령으로 직접 확인한다. 노트에 "돌고 있다"고 적혀 있어도 확인 전에는 그렇게 보고하지 않는다.
